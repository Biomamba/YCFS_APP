Biomamba 言出法随 · Windows 版使用说明
========================================

一、怎么打开
------------

  解压这个压缩包（**整个文件夹一起解压**，不要只把 run_app.bat 拖出来），
  然后双击：

      run_app.bat

  浏览器会自动打开，地址是 http://127.0.0.1:8899/
  （要是 8899 被别的程序占着，它会自己往后找一个，黑窗口里会写明这次用的是
  哪个端口 —— 以窗口里那句为准。）

  ⚠️ 不要只复制 run_app.bat 一个文件到别处 —— 它要和旁边的 runtime\ 文件夹
     在一起才能用。少了它会提示 "No R runtime found"。

二、这个版本不需要你装任何东西
------------------------------

  旧版要先装 R、再装一堆 R 包，而且 R 必须装在固定的路径下，否则打不开。
  这个版本把 R 和所有依赖包都**打包在里面**了（就是 runtime\ 那个文件夹，
  比较大，属于正常现象）。

  你机器上装过别的 R 也不影响，它用的是自带的那一份。

三、第一次使用
--------------

  第一次打开会落在**注册**页。填完就是这台电脑的管理员。

  ⚠️ 它给你的**恢复码只显示这一次**，请抄下来存好。以后换电脑、或者忘了
     密码，就靠它。

四、我的数据在哪
----------------

  默认在解压出来的文件夹里（就是 run_app.bat 旁边那个 data\）：

      <你解压的位置>\data\

  对话记录、上传的文件、跑出来的结果都在那儿。**整个文件夹拷走 = 搬家**，
  换一台电脑接着用。

  如果这个位置写不进去（比如你把文件夹放进了 C:\Program Files\，或者从
  只读的 U 盘/网盘直接运行），程序会自动改放到：

      %LOCALAPPDATA%\DS_App\data

  启动时那几行字里会写明这次用的是哪一个，看一眼就知道。

  想固定到别的地方：在 run_app.bat 旁边新建一个 .Renviron 文件，写一行

      DSAPP_DATA_ROOT=D:/我的数据/DSApp

五、关掉它
----------

  关掉那个黑色命令行窗口就是停止服务。浏览器那个页面关不关都行。

六、这个版本和网页版的关系
--------------------------

  界面、功能、账号那套（注册/密码/恢复码）是**同一套代码**，数据库各自
  独立，**但对话可以同步**：

      · 这台电脑上的账号、对话、任务，默认只存在这台电脑上；
      · 「对话」可以同步到服务器 —— 设置 → 数据同步，填服务器的地址、
        登录用户名和同步目录，然后点同步；
      · 同步过去的是**对话**（会话 + 消息）。任务、跑出来的文件、环境、
        API Key **不同步** —— 那些东西只在这台电脑上真实存在，搬过去
        点开是空的，比不同步更让人以为"东西丢了"。

  同步要配一次到服务器的登录方式（密码或密钥），只用于传文件，不写盘。

  ⚠️ **同一个邮箱在这台电脑和服务器上是两个账号行**。同步是「我的数据
     跟着我走」：两边用**同一个邮箱 + 同样的密码**登录，服务器才认得出来
     这个包是你的。**密码不一样的话同步会被拒**（这是有意的 —— 包是用
     密码推出来的一把密钥签的名，服务器验不过就不收）。

  ⚠️ 点同步之前必须**用密码登录过**（不是恢复码）。原因同上：密钥是从
     密码现推的，恢复码推不出来。用恢复码登录之后点同步，会提示你重新
     用密码登一次 —— 这不是出错，是设计如此。

  不想配同步、就只想把数据搬走的话，整个文件夹拷走也行：对话记录、上传的
  文件、跑出来的结果全在 data\ 里，拷到另一台电脑同一个位置接着用。

七、出问题了
------------

  · 双击没反应 / 一闪而过：右键 run_app.bat → 编辑，看看是不是中文路径
    导致的（把文件夹放到 D:\DS_App 这种纯英文路径下试试）。
  · 提示 "No R runtime found"：runtime\ 文件夹没解压出来，重新完整解压一次。
  · 提示端口被占用：说明已经开着一个了，看看任务栏里是不是有个黑窗口。
  · 杀毒软件报警：这个包里自带了一个完整的 R 解释器（就是 runtime\ 那三百
    兆），而"一个会执行脚本的解释器"正是杀毒软件启发式规则敏感的东西，
    加上这个程序没有买商业代码签名证书，被拦下来是常见的误报。确认包是从
    官方渠道拿到的之后加白名单，或者直接用网页版。
  · 其它报错：把黑窗口里的**全部文字**截图发我。窗口关掉就没了，
    所以请在关掉之前截图。
