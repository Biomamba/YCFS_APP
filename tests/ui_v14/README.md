# tests/ui_v14 —— Test_V14 的浏览器验收

## 怎么跑

```bash
# 1. 起一个可丢弃的实例（数据在 /tmp，线上一个字节都不动）
bash tests/ui_v7/make_instance.sh 8917 /tmp/dsapp_v14

# 2. 跑
python3 tests/ui_v14/probe_v14.py        # 退出码 0 = 全绿
```

脚本里的默认值（`URL` = `http://127.0.0.1:8917/`、`APP` = `/tmp/dsapp_v14/app`、
`OUT` = `/tmp/dsapp_ui_v14`，见 `_common.py` 顶上）和上面那条命令是**一套**，
起完直接跑就行，不用设环境变量。

> ⚠️⚠️ **起实例时别绕开 `make_instance.sh` 自己 rsync。** 仓库根目录下的
> `.Renviron` 里 `DSAPP_DATA_ROOT` 指的是**线上数据目录**。整目录 rsync 时
> 如果没排除它，实例会**连着生产库**启动 —— 而它照样能起来、照样监听端口，
> 页面上一点异样都没有。手工拷的话：
>
> ```bash
> rsync -a --delete --exclude '.Renviron' --exclude 'data/' --exclude '.git/' \
>   --exclude 'history_Version/' --exclude '*.log' \
>   /data3/biomamba/analysis/DS_App/ /tmp/dsapp_v14/app/
> printf 'DSAPP_DATA_ROOT=/tmp/dsapp_v14/data\n' > /tmp/dsapp_v14/app/.Renviron
> ```
>
> 另有一个反向的坑：`rsync -a --delete R/ <目标>/` 这种**带尾斜杠的多源**写法，
> 会把 `R/` 的**内容**摊进目标根目录，再把目标里其它东西全删掉（`app.R`、
> `www/`、`selftest.R`……）。实例会起不来，报 `App dir must contain either
> app.R or server.R`。源必须是**仓库根**、并且带尾斜杠。

> ⚠️ 实例里 `R/*.R` 只在**进程启动时** source 一次（这里是 `shiny::runApp`，
> 没有线上那套 worker 换代）。**改完 R 代码必须重起实例**才看得到 ——
> 而 `make_instance.sh` 会从仓库重新拷一份（于是变异会被覆盖掉）。
> 这两件事的取舍见下面「变异验证」一节。

> ⚠️ 本探针**不需要**假模型服务，一次模型调用都不发，只量界面 + 点按钮。

## 这一版管什么

| 工单 | 一句话 | 断言 |
|---|---|---|
| item 1 | 文件管理区和预览之间能拖动改大小 | 两栏并排不重叠；往右拖 120px 管理区**真的变宽**；双击恢复默认；**刷新之后还是拖过的那一档**（写进 uipref 了）|
| item 4 | 分析报告预览时 html 里的图片是裂的 | 上传 html+png → 点预览 → iframe 里 `naturalWidth > 0`（真的解码了，不是裂图）；`src` 是 `data:` URI；**反向**：指向不存在文件的图仍然是裂的 |
| item 5 | skills_builtin 下那三个 html 要进技能库 | 三条新技能都在（顶层散放 `.html` 是扫不到的）；每条展开后有配套 `.html` 附件；老的几条还在 |
| item 6 | 告诉用户算力节点是谁的机器 | 「当前挂载服务器」写明是**本站的部署机**、**不是你的机器**；另外两项（远程服务器 / 我的本地电脑）的物主也写了；部署机身份（主机名/核数/内存）给出来了；**反向**：页面上没有留下「当前服务器」这种相对说法 |
| item 7 | 「配额与资源」里加 GPU 开关 | 弹窗里有 GPU **三选一**（跟着平台默认 / 允许 / 禁止）；选「允许」保存后库里 `gpu_enabled = 1`；**重新打开弹窗回显「允许」**；换回「跟着平台默认」写的是 **NULL 不是 0** |

item 2（文件管理区默认按修改时间倒序）和 item 3 的**自检那一半**不在这个探针里
—— 它们不需要浏览器：`dsapp_files_order()` 和 `dsapp_dl_plan()` 都是纯函数，
`selftest.R` 里各有一节直接断言（见下）。

### 为什么这几条非要在浏览器里再验一遍

自检（`Rscript selftest.R`）已经把源码证到位了。浏览器这一边回答的是另外几个
问题，它们可以各自单独坏掉而源码级断言全绿：

1. **item 4 / 7 都是"跨了四层、少一层就静默失效"的那类。** 自检能证明
   `dsapp_html_inline()` 拼对了字符串、能证明 `dsapp_user_set_gpu()` 三态存取
   正确，但它证明不了**预览那条路真的调了内联**、**弹窗里那三个 radio 真的
   画出来了并且接上了保存**。
2. **item 1 的拖动是纯前端。** 指针事件、`setPointerCapture`、写 uipref 的往返
   —— 一行 R 都不经过，自检看不见。
3. **item 6 是纯文案。** 唯一能验的就是"页面上那一刻显示的是哪几个字"。
4. **"有没有真的画出来"只有浏览器知道。** 一个 `renderUI` 崩掉时 Shiny 把
   **那一整块**换成一句报错，表现不是"少了一行"而是"一条都没有"。

## 五个坑（都踩过，别再踩）

**1. ★★★ 探针报的"红"可能是探针自己写错了 —— 先证明它会红，再信它的绿。**
这一版是照着自己的想象写断言的，第一跑红了 4 条，逐条查下来**只有 1 条是真的**
（item 4），另外 3 条是探针的问题：

| 症状 | 真相 |
|---|---|
| `item04 theimg 找不到` | **真 bug**，见下面第 2 条 |
| `item06 ✗ 另外两项的物主也写了` | 断言照自己想象的文案写（「你自己的服务器」），页面上写的是**下拉框的选项名**（「远程服务器」/「我的本地电脑」）|
| `item07 管理页画不出账号表` | 本轮账号**不是平台管理员**，管理页压根不渲染 |
| `item07 回显 ✗ []` | 弹窗**根本没打开**，`[]` 是"没有勾选项"和"没有弹窗"共同的样子 |

**2. ★★★ `dsapp_html_inline()` 换 src 时少拼了一段（已修）。**
`paste0(a[[2]], a[[3]], uri, a[[3]], a[[5]])` —— `a[[5]]` 是**闭引号**，
`a[[6]]`（标签剩余部分，含结尾的 `>`）从来没被拼进去。于是
`<img src='a.png' id='x'>` 被换成 `<img src='data:...'`：**id/class/style 全丢，
连 `>` 都没了**，后面那个 `<` 被浏览器当成属性名吃掉（实测 `</body>` 会变成
img 上的 `body=""`）。
⚠️ 它**躲过了当时所有的测试**：`src` 是对的，**图照样显示** —— 所以"图裂了没有"
这一类断言全绿，坏的是属性和图后面那一小段标记。探针能抓到它，靠的是
`document.getElementById('theimg')`（id 没了就返回 null）。
教训和 V13.17 的 `wall_limit` 一样：**没断言的功能等于没改**。

**3. ★★ `#admin-tbl` 必须带 id，不能写 `table`。**
bslib 把所有页都留在 DOM 里，`table:first` 命中的是**文件页**那张表（它第 0 列
正好是「去预览」）—— 于是 Playwright 去点一个隐藏元素、等 30 秒超时，报
"element is not visible"，看着像"管理页没画出来"。同理 `.dsapp-page .nav-link`
那类限定词不能省（只写 `text=执行` 会先命中对话页的「确认执行」按钮）。

**4. ★★★ 管理页：保存之后**必须重新选那一行**，而且"选中"要回读。**
`confirm_quota_limits` 里调了 `refresh()`，账号表重画 —— 而 **DataTable 重画会
清掉选中行**。此时 `selected()` 是 NULL，服务端第一句就
`return(note("先在表里选一个账号。"))`：**弹窗根本不出现**（不是弹窗内容错，
是压根没有弹窗）。所以 `_select_self()` 里点完要等 `tr.selected` 真的出现
（最多 3 次），`_open_limits()` 整段可重试。
两类动作都必须**按邮箱筛出自己那一行**再点：表按 id 升序、第 1 行是**最早那个
账号**；每页 10 行，跑过十几轮之后本轮那行会翻到第 2 页。

**5. ★★ 别让脚本炸 —— 一炸，后面整段都"没跑到"。**
`pg.wait_for_selector()` 超时抛 `TimeoutError`，脚本当场结束（`main()` 会把它记成
一条红的 `xxx 抛异常`）。等待一律走不抛异常的写法 + `.count()` 兜底。
⚠️ 但**别把兜底写成"永远返回空数组"**：`eval_on_selector_all` 在**不存在**的
选择器上返回的是空数组、不抛错 —— 那正是上面第 4 条"没有勾选项"和"没有弹窗"
分不开的原因。**先断言那个东西在，再读它的内容。**

## 这一版做过变异验证

按仓库约定，承重最大的几条断言都反向验过 —— **改坏实例副本**（不是源码，
更不是线上那份）看它会不会红。变异要能生效，重起实例时**不能**从仓库重新拷：

```bash
# 只停旧 pid + 重起，不重新拷代码（make_instance.sh 会把变异覆盖掉）
cat > /tmp/restart8917.sh <<'SH'
OLD="$(ss -ltnp 2>/dev/null | grep ":8917 " | grep -oP 'pid=\K[0-9]+' || true)"
[ -n "${OLD:-}" ] && { kill "$OLD" || true; sleep 2; }
cd /tmp/dsapp_v14/app
R_HOME=/usr/lib/R nohup /usr/lib/R/bin/exec/R -q \
  -e 'shiny::runApp(port = 8917, host = "127.0.0.1", launch.browser = FALSE)' \
  > /tmp/dsapp_v14/app.log 2>&1 &
SH
```

| 变异 | 改哪儿 | 结果 |
|---|---|---|
| A：把修好的 `a[[6]]` 改回 `a[[5]]`（**就是上面那个真 bug**）| 实例的 `R/files.R` | item 4 红 **3** 条：`★★★ 图片真的解码出来了 → no-img`、`★★ data: URI`、`★ 反向：不存在的图仍然是裂的` ✔ 正是它该抓的 |
| B：「允许」那一支改成写 `FALSE` | 实例的 `R/mod_admin.R` | item 7 红 **2** 条：`★★★ 库里 gpu_enabled = 1`（实际 `(0,) \| 回执: …GPU 已允许。`）、`★★★ 回显「允许」`（实际 `['deny']`）✔ |

> ★ 变异 B 那条报出来的细节正好说明**为什么回执要一起报**：库里的值是 `0`，
> 而页面回执写着「GPU 已允许」—— 两句话直接矛盾，一眼能看出是保存那一支写错了，
> 而不是"UI 没接上"。只看 `(0,)` 的话，这两种原因是分不开的。

变异做完**从仓库整份拷回去**（直接再跑一次 `make_instance.sh`）再跑一遍，
确认 43 条全绿。验收时的实测数：自检 **2771 条全绿**（`EXIT=0`），探针 **43 条全绿**。

## 这一版的自检补了两节（都是"事后补的"）

`selftest.R` 里新增 **23** 条（2748 → 2771）：

- **V14 item 3/4：图片内联进 HTML**（13 条）。核心是那条
  `★★★ 换完之后**整个标签**还是原来那个` —— 它把重建后的整段标签写成字面量，
  少拼任何一部分（属性、闭引号、结尾的 `>`）都会红。另有一组盯
  "同一个文件引两次只算一次字节"（一张 logo 引几十次能把报告撑爆）和
  "已经自包含的文件第二次跑不动它"（否则每跑一次任务 mtime 就跳一下）。
- **V14 item 3 下半句：md 下载连依赖一起打包**（10 条）。含 **zip slip**
  （`../../` 爬出工作区的引用不能变成依赖）和
  **"名字和内容必须对得上"**（`kind == "zip"` 时下载名必须以 `.zip` 结尾 ——
  下载名和内容是两处单独算的，各判一次 kind 就会给用户一个叫 `报告.md` 的 zip，
  双击打不开而且看不出是谁的错）。

两个 R 的坑记在这儿：写这一节时断言自己先红了一次，原因是
**`strsplit()` 会把结尾那个空字段吃掉**（`strsplit("a\nb\n","\n")` 只给两个），
而 `writeLines()` 写完**会再补一个结尾换行**，所以按行比对要显式写 `c(..., "")`；
另外**别用 `identical()` 比带中文的字符向量**，它连 `Encoding` 属性一起比
（`readLines` 读回来的带 UTF-8 标记，拼出来的字面量是 unknown，内容一样也判 FALSE），
`==` 才会先把两边归到同一种编码。

`_common.py` 是共用的：`enter_app()` 建号进应用、`seed_or_die(email)` 拿到
`(uid, db_path)` 并**确认这个实例读的不是线上库**（找不到就硬退出）、
`goto(page, name)` 切页（认 value 也认中文页名，切完回读左栏高亮）、
`txt()` 取元素文字、`Chk()` 记断言（`.done()` 返回 0/1）。
