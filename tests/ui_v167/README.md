# tests/ui_v167 —— `dsapp_linkify_files()` 回归（Test_V16.7）

V16.7 只做了一件事：修 `Biomamba_ceshi` 账号上那句
「An error has occurred. Check your logs or contact the app author for clarification.」

这一版没有浏览器探针 —— 那个报错是**渲染期抛的 R 异常**，不是界面行为问题，
所以判据全在 R 层，跑起来也不要实例、不要浏览器、不要假 LLM。

## 怎么跑

```bash
Rscript --no-environ tests/ui_v167/linkify_regression.R
```

退出码 0 = 全绿。**`--no-environ` 不是可选项**：`Rscript` 会读 cwd 的
`.Renviron`，而它会盖掉你 `env=` 传进去的环境变量 —— 本仓被这条坑过
（自检的子进程把 `app.R` 求值进了生产目录，种了两行技能进生产库）。
脚本自己在最顶上把 `DSAPP_DATA_ROOT` 指到临时目录，不碰生产。

跑完屏幕上会有这么两行，**先看它们**：

```
仓库： /data3/biomamba/analysis/DS_App
加载自： /data3/biomamba/analysis/DS_App/R/render.R   md5  666aefd489f9b27f8e886a06998632e7
```

第二行是给**变异测试和对照实例**看的：做变异时最怕的是"被测对象根本没被换掉"，
而那种情况跑出来也是一片绿（见下面「两次假绿」）。

## 两次假绿（都发生在这份脚本上，写下来给下一个人）

1. **判据写成了 `cat("✓ …", grepl(...))`** —— 那个 `✓` 是手打的字面量，
   表达式算出来是 `FALSE` 也照样打印 `✓`，而且不进计数。
   屏幕上长这样：`✓ 错的是编译这一层（不是别的意外）： FALSE`。
   → **判据一律走 `ok()`**，`ok()` 里那句 `cat("  ✓ ")` 是整个脚本里唯一的绿。
2. **变异体放错深度**，于是脚本 `source` 的是**没被变异的那棵树**，23 项全绿。
   真身的位置是 `<仓库根>/tests/ui_v167/`（比根深**三**级）；我把它放成了
   `<仓库根>/_mut2/a/`（深两级），`../..` 就正确解析回仓库根了。
   屏幕上唯一线索是那行「仓库：/data3/.../DS_App」——它长得完全正常。
   → 现在脚本会断言自己待在 `tests/ui_v167/` 里，放错就**明响**；
   并且打印 `R/render.R` 的 md5，变异前后一眼可比。
   → 做变异/对照实例时，**变异体要放在 `<变异根>/tests/ui_v167/`**。

## 这一版查出来的真 bug

`dsapp_linkify_files()` 把工作区里**全部**产物名拼成**一条**正则去匹配正文。
那个账号的工作区被模型建过一整个 Python 虚拟环境（`.venv/`），
名单 **5262 条**、拼出来 **43.8 万字符** —— R 的 PCRE2（LINK_SIZE=2）编译上限
约 64KB，直接失败：

```
PCRE pattern compilation error
  'regular expression is too large'
```

它抛在 `renderUI` 里，于是**整个 `output$chat-history` 那一格报废**，
被 `shiny.sanitize.errors` 换成那句英文。工作区文件越攒越多 = 每次重画历史都炸，
所以症状是"用着用着突然坏了"。

两处修复对应两条判据线：

- **预筛**（`dsapp_link_candidates`）—— 名字在正文里没出现就不进正则。
  `fixed = TRUE, useBytes = TRUE`；语义零变化（正则里每个分支都是字面量），
  但 5262 条扫 23KB 正文从 **219ms → 25ms**。← 判据 7、8
- **切块**（`dsapp_re_find_all`）—— 按**转义后**的字符数切成 ≤16000 字符的块，
  逐块编译；合并规则按「起点升序、同起点长的在前」贪心取不重叠，
  与原来单趟扫描**逐字等价**。← 判据 2c、6、3

⚠️ 切块依据是**转义后的字符数**不是条数：40 条 `.venv/...` 长路径比 200 条短名字
还长，按条数切照样炸（实测踩过）。
