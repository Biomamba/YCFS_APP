# Nature 系投稿级科研出图规范

从「这句话要证明什么」走到「PDF 里每个字形 ≥5 pt 且文字不撞线」的出图方法，覆盖主图、机制示意图、多面板组图与返修重画。

**最高优先级：图服务于科学逻辑。** 美观、模板匹配、复杂版式都服从于「核心结论清楚、可辩护、可被审稿人复核」。

## 什么时候按这条走

- 要出论文配图 / 多面板 figure / 机制示意图 / graphical abstract，或点名 "Nature style"、"publication figure"、SVG、高 DPI。
- 要重画已有图、改造论文版式、加面板、改配色、改图注，或审查图的逻辑与导出质量。
- 不适用：交互式图表（plotly/altair/bokeh）、纯 EDA、GIS/3D 建模、手工排版。

## 主流程

### 0. 先写图件契约（动手写代码之前）

不要从模板开始，从结论开始。先写出这一份，缺的标成待作者确认：

```text
核心结论（一句带动词的话）：
本图回答的 Results 级问题 / 要防的反驳 / 决定性证据：
图件原型：quantitative grid | schematic-led composite | image plate + quant | asymmetric mixed-modality
目标期刊与阶段：initial_submission | revision | accepted_in_principle
面板地图 a/b/c…（问题 | 证据角色 | 必要对照）：
统计（n、中心量、离散、检验、校正）/ source data / 图像完整性记录 / 审稿人风险：
```

三条硬判断：**按 claim 分组，不按源表分组**（几张表回答同一问题就合成一张图）；**每个面板必须有不可替代的推理角色**（只换指标重画的砍掉）；有数据无 claim 就先推一个暂定 claim 往下做，只有**会改变成图结果**的解释性分歧才停下来问。

### 1. 定后端，并且排他

第一次绘图前问一次、只问一次：「用 Python 还是 R？我会在本次对话里沿用。」顺序：用户指定 → 输入/工作流明显是某语言（.R / RDS / Seurat / DESeq2 输出 → R；numpy/pandas/PyTorch 输出、图像数组 → Python）→ 本对话已确立 → 再问。

选定后**排他**：绘图脚本、模拟预览、SVG/PDF/TIFF 导出、视觉 QA 渲染全部同一后端。缺运行时/缺包时停下报告，给脚本与安装命令或请求安装权限，**绝不换语言出替代图**。

- Python：matplotlib / seaborn；布局 `GridSpec`、`subplot_mosaic`。
- R：ggplot2 + patchwork（组图）、ComplexHeatmap + circlize（组学热图）、ggrepel（直标）、svglite + cairo_pdf + ragg（导出）。

### 2. 排面板证据链

一张图默认回答一个 Results 级问题；某面板自己就是独立大主张时给它另一张图。证据角色挑最小充分集：设定/示意图、代表性实例、主定量证据、基线/对照、分解、分层、正交验证、扰动/压力测试、边界/失效、机制。

**反模式**：`a: R² → b: R² 成对检验 → c: MAPE → d: MAPE 成对检验`（四面板只有两个角色）。更强：`a: 扰动设计 → b: 决定性比较 → c: 全分布或残差 → d: 分解或边界`。

**主图 / ED / SI 归属**，逐面板问：去掉它哪个独立推断消失？**主图**=决定性证据、必要对照、核心否证、会改变结论的边界；**ED/SI**=稳健性、溯源细节、次要指标、替代估计量；**另一张图**=独立另一主张；**删/合并**=同结果只换指标/估计量/阈值。不要因为结果是阴性或不好排版就藏起会改变结论的结果。

### 3. 视觉层级与页面原型

决定性证据放最大最显眼处（hero panel），对照与稳健性安静些但要大到能判断。反复出现的页面原型：

| 原型 | 规则 |
|---|---|
| schematic-led composite | 示意图占 45–60% 高度；支撑图用柔化的同一套配色，只验证不竞争 |
| image plate + quant | 黑底只用在图像 plate 内；crop、标尺、通道标签几何一致；白 gutter、白标尺 |

- 面板标签：左上角的**小号粗体小写**（终稿 8 pt），用**固定物理点偏移**而非 axes 分数偏移（`y=1.02` 在高矮不同的面板上位移不同）：`ScaledTranslation(-4/72, 3/72, fig.dpi_scale_trans)`；黑底图像面板内移并改白色。
- 图例：能直标就直标；重复图例合并成共享图例带；大图例给 legend-only 轴（最后一个 subplot + `set_axis_off()`）。默认 `frameon=False`；方法名已在图例里就 `ax.set_xticks([])`。

### 4. 尺寸、字号与导出契约

旗舰 Nature 终稿：单栏 **89 mm**、双栏 **183 mm**，高 **≤170 mm**；正文最终 **5–7 pt**（密集多面板生成时常 7–9 pt）；多面板标签 8 pt 加粗直立小写；统一 Arial/Helvetica，序列用 Courier；文字保持可编辑、不转曲、嵌 TrueType 2 或 42；主图要**矢量可编辑**（.ai/.eps/可编辑 pdf，也接受分层 psd、PPT 转 PDF、纯 svg、Excel），**不要**把平铺 jpeg/tiff/png 当主图终稿（那只作 QA/预览），组件内嵌不外链，单文件 <50 MB。**ED 另一套**：RGB、≤300 dpi、≤10 MB、优先 jpeg、一项一页、文件名按通讯作者姓氏 + ED 编号，两套不能互换。图像面板 ≥300 dpi（450 更佳），用**标尺**而非放大倍数，轴线与刻度线要在，每个轴有标签、单位进括号。

**写死在每个脚本开头**（Python）：

```python
plt.rcParams["font.family"] = "sans-serif"
plt.rcParams["svg.fonttype"] = "none"   # 文本保持 <text> 节点，可在 Illustrator 里改
plt.rcParams["pdf.fonttype"] = 42       # PDF 嵌入可编辑 TrueType
# 另：axes.spines.right/top=False；axes.linewidth=0.8；legend.frameon=False；font.size=7
```

> ⚠️ **`font.sans-serif` 那一行不要照抄英文模板。** 原来这里写的是
> `["Arial", "Helvetica", "DejaVu Sans", "sans-serif"]` —— 这三款在服务器上
> **都没有中文字形**，图里只要有一个中文标签就全变成空心方框，而任务状态是
> `success`、文件也在，从执行结果里看不出任何异常（V15.5 item 12 用户就是
> 拿着这样一张图来的）。而且**补一个中文字体到列表末尾也没用**：matplotlib
> 不做逐字回退，第一个能解析到的字体管全部字符。
>
> 图里**有中文**时，按【运行环境】→「中文字体」那一节里列出的**文件路径**
> 加载，并把它排在**第一个**（那一节还给了画完自查有没有缺字形的办法）；
> 图里**全是英文**时，上面的英文清单才适用。

导出顺序 **SVG（主）→ PDF（次）→ TIFF 600 dpi（投稿栅格）→ PNG 300 dpi（预览）**；绝不用 `svg.fonttype='path'`（字形变曲线、不可编辑）；`tight_layout(pad=2)`（紧凑多面板 pad=1），导出后 `plt.close(fig)`；无头环境先 `matplotlib.use("Agg")`。

```r
theme_set(theme_classic(base_size = 6.5, base_family = "Arial") + theme(
  axis.line = element_line(linewidth = 0.35, colour = "black"),
  legend.title = element_text(size = 6.2), legend.text = element_text(size = 5.8),
  strip.text = element_text(size = 6.2, face = "bold"), panel.grid = element_blank()))
```

### 5. 配色

语义优先：**蓝 = 提出的方法，绿 = 正向变体，红/粉 = baseline，中性 = 参考**；密集页面上**家族一致性比最大色相分离更重要**——整页要读成一张图。

```python
PALETTE = {"blue_main":"#0F4D92","blue_secondary":"#3775BA","green_3":"#8BCF8B",
  "red_strong":"#B64342","neutral_light":"#CFCECE","neutral_dark":"#4D4D4D",
  "teal":"#42949E","violet":"#9A4D8E"}
DEFAULT_COLORS = ["#0F4D92","#8BCF8B","#B64342","#42949E","#9A4D8E","#CFCECE"]
# 同族统一（多方法同门，适合 ML/密集页）：baseline #484878 / #7884B4 / #B4C0E4；
# ours #E4E4F0 / #E4CCD8 / #F0C0CC；方向性 delta_up #2E9E44，delta_down #E53935
```

规则：相关 baseline 放一个冷色家族，`Tiny/Base/Large` 同门变体放一个 hero 家族；**绿/红只留给箭头、增益、下降、阈值或有方向含义的信号**；同一方法在所有面板同一颜色；拿不准就降饱和而不是加类别；消融用**单色 + alpha 渐变**编码完整度 `np.linspace(0.2, 1.0, n)`。

**禁用 rainbow/jet/hsv**（静态预检判 FAIL）。红绿不能作为唯一编码，灰度打印必须仍可区分（hatch）；顺序色标浅→深表达次序或量级，**不能**当无关分类色重用。

### 6. 常用图型的做法

- **竖条比较**：`edgecolor="black", linewidth=1.5, capsize=5`，`error_kw={"elinewidth":2,"capthick":2}`；条内数值按底色亮度选黑/白字（`0.299r+0.587g+0.114b < 0.5` → 白字），位置从数据与误差上界推；灰度安全用 `hatches = ['/', '\\', '.', 'x', 'o']` 逐个 `set_hatch` 并描边。
- **热图**：按列归一化；发散 `RdBu_r`、单向顺序色标；`cmap.set_bad('white')`、`set_frame_on(False)`、去 tick marks 留标签；单元格文字按亮度取黑白；可补 z-score 偏差图（`vmin=-2.5, vmax=2.5`）。

### 7. 数据完整性（不可让步）

- 默认使用**全部**用户提供的观测和要求的变量。任何行/列/重复/图像/类别的排除必须有科学或统计理由或用户明确要求，并记录**排除前后计数 + 精确规则 + 原因**；保留未修改的源数据。
- 大点云不要为好看或快而抽样：用栅格化 marker、hexbin/密度、声明规则的聚合；抽样须记录方法、样本量、随机种子。模拟值不得留在交付里（走显式 demo 标志）。

### 8. 复用别人的图/模板

先定级：**精确复用**（含义、数据形状、变换、后端全一致 → 只改路径/标签/输出前缀）；**结构适配**（含义与维度一致、字段名不同 → 显式字段映射 + 变换守卫）；**只继承样式**；**重写**（回答另一个问题或换统计逻辑）。改前写清 `模板字段 → 用户字段 → 角色 → 单位 → 允许值`、分组字段、重复单位（生物/技术）、不确定性来源与定义。

第三方参考素材可能**没有明确许可证**（例如素材库里保留的 `figures4papers` 脚本与预览图，上游未声明 LICENSE）：只学 layout/legend 与多指标比较语法，**不要复制、修改、再分发或发表**其文件或衍生材料；用原创代码 + 用户数据重实现。

## 渲染后 QA

### 9.1 导出前：多面板对齐门（≥2 个可比面板必做）

在最终布局（图例、colorbar 都定型）之后、导出之前，测量**最终渲染的 plot-area 矩形**并保存对齐 JSON，默认物理容差 **1.5 pt**（约 0.53 mm）。查：同行共同上下边界 + 等高；一行 3/4 张**等网格跨度**面板最终宽度也相等；同列共同左右边界 + 等宽；不等跨度网格共享外侧起止边界（跨行面板只与上下小面板比共享外边）；≥3 个可比面板的重复 gutter 一致；左上粗体小写标签的锚点一致；矩形互不重叠。

| 结论 | 动作 |
|---|---|
| `NOT APPLICABLE`（单面板，exit 0） | 保留 JSON，继续 |
| `PASS`（exit 0） | 保留 JSON，进入导出/PDF QA |
| `FIX BEFORE DELIVERY`（exit 1） | 改版式重跑，**不要**导出交付包 |
| `REVIEW REQUIRED` | 逐条复核 WARN 并记录理由；`--strict` 时 WARN 阻断 |
| `NOT AUDITABLE`（exit 2） | 补齐几何/比较组，**不得**声称对齐通过 |

### 9.2 导出后：PDF 渲染碰撞审计（改了布局就要重跑）

**不要复用上一次的报告**；改了文字、字体、图例、标注、轴、数据或面板排布就重跑。它读 PDF 几何，对 Python 和 R 输出同样适用，但不改图；带框诊断 PDF 只是 QA 产物。

| 结论 | 含义 → 动作 |
|---|---|
| `text-text` FAIL | 两个渲染文本框实质重叠 → 分离/缩短/旋转/缩字号后重跑 |
| `text-stroke` FAIL | 线/曲线/marker 边/误差棒穿过文字内部 → 移文字或改布局；**不要**用不透明白底遮罩盖线 |
| `text-page-clipping` FAIL | 文字超出页面 → 扩版式/移位置后重导出 |
| `text-fill-edge` / `text-image-edge` WARN | 文字只部分压住色块或 raster 边界 → 最终尺寸下看，非有意就修 |

`FIX BEFORE DELIVERY`/exit 1 阻断交付；exit 2 或 `NOT AUDITABLE` 表示没检查成功，**不得**报成通过；`REVIEW REQUIRED` 不等于静默通过。

### 9.3 字形下限与逐面板人工审查

扫描导出 PDF 内容流的 `Tf` 字号操作符，要求**每个文本 run ≥5 pt**（比查源码 `fontsize` 可靠）：matplotlib mathtext 常把上下标缩到约 **0.7×**，7 pt 的 `$R^2$` 上标只有约 4.9 pt——能保持记号含义就改 Unicode `R²`，否则抬高父字号并用 PDF 审计确认。自动检查不能替代人工：在**最终物理尺寸**下逐面板看，并留一张表 `Panel | 独有主张 | 中心量 | 离散/区间 | 重复单位 | 标签/图例 | 对齐组/结果 | 碰撞结论 | 通过`；盖住某面板后论证依然完整就合并或删掉；并排比较重复面板的术语、不确定性、轴范围与颜色映射是否一致；加误差线后删掉重复编码同一 gap 的箭头/括号；标签位置从数据与不确定度边界推（`max(center+spread)+margin`），不要用固定 `LABEL_Y`。

## 判据与阈值速查

| 项目 | 默认 | 何时改 |
|---|---|---|
| 单栏 / 双栏宽度 | 89 mm / 183 mm | 目标期刊另有规定以期刊为准 |
| 主图最大高度 | ≤170 mm | 同上 |
| 正文最终字号 | 5–7 pt（密集多面板常用 7–9 pt） | 幻灯片级大面板 15–24 pt |
| PDF 字形下限 | 每个文本 run ≥5 pt | 期刊要求更高时提高 |
| 对齐容差 | 1.5 pt（gutter 同为 1.5 pt） | 不因单个例外放宽全局 |
| 碰撞阈值 | 重叠比 0.05；文字内缩 0.6 pt；裁切容差 0.5 pt | — |
| 栅格分辨率 | TIFF 600 dpi；<300 FAIL，<600 WARN | 图像面板最低 300（450 更佳） |
| 图注词数 / 图件数 | 旗舰 Nature 整条 <250 词；NMI 150–250 词、主图+表 ≤6、ED ≤10 | 以投稿系统或编辑最新指示为准 |

## 图注与统计标注

**骨架**：`Fig. N | ` + 加粗名词短语总题（标题行不放数字和结果）→ `a / b / c` 逐面板描述，**现在时、电报式、常省略主语**（制作方法用过去时）→ 统计写进图注（`mean ± 95% CI (n = 1373) … one-way ANOVA with Tukey correction`）→ 结尾 `Source data are provided as a Source Data file.`。图注要能脱离正文读：颜色/形状映射、样本量、关键数值锚点（PDB id、RMSD、单位）都写进去；不复述结果、不重写 Methods。每个定量面板至少要能填出：`n` 定义、生物/技术重复、中心统计量、离散/区间、检验、多重比较校正、p 值显示方式、source data 文件。

**展示标签**：普通描述首字母大写（`Tuned XGBoost`、`+ Semantic guidance`），但**保留** `XGBoost`、`DeepSeek`、`GPT-5.2`、`RF` 这类规范拼写，**绝不**对标签批量 `.title()`。**星号**不要只写 `*P<0.05…`，要写成「符号表示经 X 检验 + Y 校正后的 p 值…；精确 p 值与样本量见 Source Data；n 表示独立 …」。

统计红线：不要把细胞/视野/读数当独立重复；不要用「一个比较显著、另一个不显著」推断两个效应有差异（要检验交互或直接比效应量）；不要用星号代替效应量与不确定性；报告不了的 n、检验、软件版本标成待作者确认，**不要编**。

## 常见坑

1. **源码字号合规但 PDF 里有 <5 pt 字形** —— mathtext 上下标约 0.7×。改用 `R²` 或抬高父字号，并对 PDF 跑 `Tf` 审计。
2. **多面板「看着对齐」但轴框不等宽/不等高** —— 肉眼和 `y=1.02` 分数偏移都不可靠。用固定物理点偏移 + 渲染时测 plot-area 矩形 + 1.5 pt 容差门。
3. **为出预览临时换后端** —— 所选后端缺包。停下报告、给安装命令或请求安装，不跨语言出替代图。
4. **文字压线后用不透明白底遮罩盖住** —— 遮罩会在曲线上切出显眼的洞。从数据与不确定度边界推标签位置；加误差线后要**重新计算**净空，并删掉重复编码同一 gap 的箭头/括号。
5. **`np.interp` 在递减网格上静默返回「看起来合理」的错值** —— 用严格单调插值 helper（自动同步反转 `xp`/`fp`、拒绝重复或方向变化）。
6. **同一方法在不同面板换色/换顺序** —— 建方法→颜色的语义映射表，跨面板复用，顺序固定。
7. **热图用 rainbow/jet** —— 读者读不出量级。发散用 `RdBu_r`、单向用顺序色标，并查灰度可读性。
8. **一张源表一张图** —— 先按 claim 分组，再合并/降级/删。
9. **把细胞数、视野数、读段数当 n** —— 伪重复、假精度、p 值偏小。以独立实验单位（动物/患者/批次/供体）为 n；技术子样本先聚合或走混合效应模型；可比面板用同一种误差线定义。
10. **强迫所有面板等大，或把图注写成第二份 Methods** —— hero 面板跨行跨列，其余按证据价值排；图注只做「描述 + 自足 + 统计」。

## 投稿 / 返修阶段与 AI 示意图

先记录阶段再套规则：`initial_submission`（格式可宽松，图可嵌在正文里）→ `revision`（同时服从编辑的具体指示）→ `accepted_in_principle`（production 级主图与 ED，两套契约不同）→ `proof`（只改生产错误，不引入新主张）。**不要**用 production 要求卡初投稿（初投稿可把图嵌在正文里、不要求美术级文件），也**不要**把预览图当可上传终稿。返修改图：把每条审稿意见映射到一个动作（改文字/补分析/补实验/**改图**/澄清已有/加引用/削弱主张/部分接受/超出范围）；改图后重跑对齐门与碰撞门、更新 source data 与图注，并保证正文、图表编号、术语与单位在正文/图注/回复信之间同步。

**AI 辅助 graphical abstract / 机制示意图**（仅当用户明确要求时）：先过**政策门**——查目标期刊最新的 AI、图像完整性、版权与披露规则并记录页面与访问日期，查不到就标「内部设计稿——投稿资格未核实」。写清沟通简报（读者要记住的一句话、图件类型、证据边界「证明了什么/绝不能暗示什么」）与视觉简报（阅读路径、高对比可访问配色、最强强调色留给中心因果步骤）。**不让** AI 编造测量值/机制/引文/标签；交付前人工核验方向/尺度/标签与单位、最终尺寸可读层级、原创性与授权，并保留 provenance（提示词、模型与版本、日期、人工修正日志）。

## 交付物清单

- 可运行脚本：选定后端、自包含、不含私有路径与 demo 数据。
- 图件：`figure.svg`（主）+ `.pdf` + `.tiff`（600 dpi）+ `.png`（300 dpi 预览）。
- **source data**：每个定量面板可追溯到干净的 CSV/TSV/XLSX 或脚本输出，含面板映射。
- QA 记录：逐面板审查表、排除的前后计数与规则、变换/守卫改动、未决风险；图注含 `n`、重复定义、中心量/离散、检验与校正、source data 句；图像面板记录 raw、processed、crop、亮度/对比/gamma、伪彩、标尺校准、拼接与复用情况。
