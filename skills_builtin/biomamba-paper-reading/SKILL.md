# 文献结构化精读

## 什么时候用这条技能

用户给了**一篇具体的文献**（DOI / PDF / 标题），要你读懂它、讲清楚它的方法、
或者判断"这篇对我们有什么可借鉴的"。

三条边界，先分清楚：
- 用户还没锁定读哪篇、只是要"找找这个方向有什么" → 那是**文献检索**的活
  （见 `文献速递` 技能），先检索再精读。
- 用户要**写**文章 / 综述 → 那是写作技能。
- 用户要**复现文中的代码** → 读完方法学那几节之后，接着走
  `教程代码结构化蒸馏` 那条技能。

⚠️ 精读的交付物是**笔记**，不是摘要。一段两百字的摘要谁都能让模型写，
  精读值钱的地方是：**这个结论是怎么一步步推出来的**、**哪些参数原文没说**、
  **哪一步我们能搬到自己课题里**。

---

## 一、八模块骨架

| # | 模块 | 必须回答的问题 |
|---|------|----------------|
| 1 | 文献元信息 | 标题（**中英同格**：`英文原题（中文译名）`）/ 期刊与 IF / 时间 / DOI / 单位 / 一句话结论（≤50 字） |
| 2 | 科学问题与创新点 | 痛点 + 3 个创新点（方法学 / 生物学发现 / 数据集）+ 转化价值 |
| 3 | 实验设计与队列 | 样本类型、物种、数量 / 组学技术清单 / **对照设置逻辑** |
| 4 | 核心分析流程 | 原始数据 → 结论的完整管线；每步工具 + 版本；关键 QC 阈值；注释策略 |
| 5 | 关键结果与图表解读 | Figure 逐张：问题 / 统计方法 / 结论 / 图型 |
| 6 | 数据与代码资源 | GEO/SRA 编号、GitHub、补充材料入口 |
| 7 | 对我们工作的可借鉴点 | 可迁移方法 / 踩坑细节 / 适合引用在哪一节 |
| 8 | 待深入学习 / 延伸阅读 | 关键参考文献 3–5 篇 + 后续追踪点 |

## 二、三条硬规矩

**1. 原文没写的，写「原文未披露」，不要补全。**

这是整条技能里最重要的一条。精读笔记会被下游当成事实使用 —— 有人照着它
设阈值、照着它选工具版本。模型"顺手补一个合理的默认值"（比如把 QC 阈值
写成 200–5000 基因、MT% < 10）最危险：**它看起来完全合理，而且没人会去
核对**。原文没披露就写"原文未披露"，读者自己去问作者或找补充材料。

**2. 作者的话和你的话要分开。**

作者原话、编者按用【作者观点】标出来；你的判断、你的类比、你认为可以迁移
的地方，放在模块 7，并且用"我们"的口吻。混在一起之后，半年后没人分得清
哪句是原文、哪句是当时顺手写的感想。

**3. 图要逐张读，不能只读正文。**

高分文章的结论经常**只在图里**（补充图里的阴性对照、某个 marker 的
表达比例）。模块 5 按"这张图在回答什么问题 → 用了什么统计 → 结论是什么"
来写；遇到看不懂的图，如实写"这张图想表达 X，但正文没有解释统计方法"。

## 三、模块 3 和模块 4 最容易写空

这两节是笔记的**主要价值**，也最容易退化成复述摘要：

- 模块 3 的核心是**对照逻辑**。不写"n=3 vs n=3"，要写"为什么拿正常瘢痕
  当对照而不是正常皮肤"（因为要排除"瘢痕 vs 正常皮肤"这个混杂）。作者选了
  什么对照、为什么这么选，是判断这篇结论可信度的第一手材料。
- 模块 4 的核心是**每一步的可复现性**。工具和版本、关键阈值、注释策略
  （用经典 marker 手注、还是 SingleR/CellTypist 自动注、还是两者互证）——
  这三样决定了别人能不能复现出同一张 UMAP。

## 四、交付物与落盘

- 一篇文献一份笔记，文件名带**第一作者 + 年份 + 关键词**
  （`Deng2021-瘢痕疙瘩成纤维细胞.md`），不要叫 `文献笔记.md`。
- 多篇读完之后，另起一节做**横向提炼**：几篇的共性套路、互相矛盾的地方、
  合起来能支撑什么判断。单篇笔记给不出这个，而它往往是用户真正想要的东西。
- 出 HTML 时：图片一律 base64 内嵌进 HTML 本身，不要用相对路径引用附件目录
  —— 用户会把这个文件单独发给别人。
- 标题那一格写 **`英文原题（中文译名）`**，中英在**同一个单元格**里。
  ⚠️ 中文译名必须是中文：**不许**把英文原文回填进中文栏充数，**不许**写
  「（我们译）」「（待译）」这类过程性标注，也不许只译一半 —— 半句英文混在
  中文栏里，读者会以为那本来就是原文标题的一部分。译不出来就如实写
  「原文未披露」。（真出过：脚本里按关键词匹配硬翻，关键词没匹配上就静默
  回填了英文原文，中文栏最后是英文、标签却写着"我们译"。）

## 五、完整范例

本技能目录下的 `Biomamba文献阅读skills-蒸馏笔记.html` 是一份**填满的**成品：
8 模块全填，含 4 篇代表作（NC 2021 / Nature 2022 / Cell 2024 /

⚠️ 单文件 HTML，浏览器直接打开。要写多篇横向对比时，照那一节的组织方式走。
