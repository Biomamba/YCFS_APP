模块 2 · 科学问题与创新点

  • 痛点：皮肤纤维化疾病（瘢痕疙瘩、硬皮病等）缺乏根治手段；既往单细胞研究集中在肺纤维化/系统硬化，皮肤纤维化中成纤维细胞异质性图谱空白。
  • 创新点（方法学）：scRNA-seq 全景分群 + 流式分选特定亚群（CD90⁺/CD266⁺/CD9⁻）做 bulk RNA-seq 互证 —— 单细胞发现、流式验证、bulk 定量的三角互证范式。
  • 创新点（生物学发现）：定义 secretory-papillary / secretory-reticular / mesenchymal / pro-inflammatory 4 亚群；mesenchymal 亚群扩增在瘢痕疙瘩与硬皮病中保守存在，POSTN 是其促胶原效应的关键介质。
  • 创新点（数据集）：首个人瘢痕疙瘩真皮单细胞图谱（40,655 个细胞），已公开可复用。
  • 转化价值：间充质成纤维细胞亚群为抗皮肤纤维化治疗提供细胞层面的潜在靶点。

模块 4 · 核心分析流程

原始 fastq → CellRanger（版本原文未披露）比对定量 → Seurat 质控/标准化/降维聚类（nFeature、MT% 等阈值原文未披露）→ 细胞大类注释（经典 marker）→ 成纤维细胞亚群细分与 marker 鉴定 → 组间亚群比例比较 → 流式分选验证亚群存在性 → bulk RNA-seq 对比验证 → 硬皮病数据跨疾病验证 → POSTN 功能实验。
  • 注释策略：marker 基因人工注释；4 亚群以功能分泌特征命名（secretory-papillary、secretory-reticular、mesenchymal、pro-inflammatory），参考既有真皮成纤维细胞单细胞文献。
  • 验证层级：计算结果须经流式 + bulk + 体外功能三级验证（本文的可贵之处）。

模块 2 · 科学问题与创新点

  • 痛点：CRC 中 ICB 仅对部分患者（尤其 MSI-H/dMMR）有效，治疗过程中 TME 与全身免疫如何动态重塑、为何响应不同，缺乏系统刻画。
  • 创新点（方法学）：连续多点采样（血/瘤/邻近正常 × 多时间点）+ scRNA-seq + scTCR-seq 的时空整合设计；从治疗过程分解出"细胞程序（cellular programs）"的协变分析框架。
  • 创新点（生物学发现）：鉴定 TLS-like、肿瘤富集、组织重构三类响应相关细胞程序；肿瘤内"血液来源 Ttr-like 细胞"呈低耗竭表型且其丰度预示更好疗效。
  • 创新点（数据集）：22 例患者 169 例连续样本的 CRC 免疫治疗动态单细胞图谱。
  • 转化价值：外周血 CD8⁺ T 细胞基线 MHC-II 相关签名 → 无创疗效预测标志物候选。

模块 2 · 科学问题与创新点

  • 痛点：耗竭性 T 细胞由 TPEX（TCF1⁺ 前体）维持，但 TPEX 内部异质性、长期自我更新与检查点阻断响应的分子开关不明。
  • 创新点（方法学）：LCMV Clone 13 慢性感染 + P14 TCR 转基因 + TCF7-GFP 报告小鼠的多层模型体系；scRNA-seq 与分选 bulk RNA-seq 互补验证。
  • 创新点（生物学发现）：TPEX 分为 CD62L⁺（真干样）与 CD62L⁻ 两群；c-Myb 身兼双职——维持干性/自我更新 + 主动诱导功能耗竭以防止致死性免疫病理。
  • 创新点（数据集）：慢性感染 d28 的 TCF7-GFP⁺ P14 单细胞图谱 + 三亚群分选 bulk 数据。
  • 转化价值：CD62L⁺ TPEX 是增强 ICB 与细胞治疗（CAR-T/TIL）持久性的新靶点。

模块 2 · 科学问题与创新点

  • 痛点：中性粒细胞半衰期短（6–8 h）、mRNA 含量极低（0.33 μg/百万细胞，约为巨噬细胞 1/8），泛癌尺度的系统图谱长期缺失；其促癌/抗癌角色争议不休。
  • 创新点（方法学）：17 癌种 225 样本整合建库策略（自测 79.29%）+ Ro/e 组织偏好 + 4 种轨迹算法交叉验证 + 单细胞代谢通路活性分析 + 空间转录组/mIHC 多模态验证链。
  • 创新点（生物学发现）：HLA-DR⁺CD74⁺ 抗原呈递型中性粒细胞（终末成熟态）关联良好预后；亮氨酸 → 线粒体结构功能重塑 → 乙酰辅酶 A↑ → MHC-II 启动子 H3K27ac → 抗原呈递程序的完整"代谢-表观"调控链。
  • 创新点（数据集）：首个泛癌中性粒细胞单细胞图谱（143 患者/225 样本）。
  • 转化价值：抗原呈递型中性粒细胞过继回输、亮氨酸饮食辅助 ICB 的治疗新策略。
