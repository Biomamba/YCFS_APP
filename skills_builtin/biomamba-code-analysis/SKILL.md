# 教程代码结构化蒸馏

## 什么时候用这条技能

用户丢来一篇教程、一段课程代码、一个复现仓库，要你「看懂它」「整理成笔记」
「以后能照着跑」；或者你自己刚在某个工作区里跑通了一套流程，要把这次的做法
沉淀下来。

反过来，如果用户只是要**跑**某个分析，直接用对应的方法学技能（比如
`单细胞标准流程（Seurat）`），不要先给他产出一份笔记 —— 笔记是交付物，
不是过程。

⚠️ 这条技能产出的是一份**结构化文档**（默认 Markdown，用户要 HTML 就出
单文件自包含 HTML）。不要把它写成"代码 + 几行说明"的流水账：九个模块里
最值钱的是**参数为什么这么定**和**报错了怎么办**，那两块不写，笔记过两周
就没人看得懂。

---

## 一、九模块骨架

拿来就用，模块名不要改（改了以后两份笔记没法对比）：

| # | 模块 | 必须回答的问题 |
|---|------|----------------|
| 1 | 教程元信息 | 主题 / 适用对象 / 软件与版本 / 运行时间与硬件 |
| 2 | 学习目标与前置知识 | 解决什么问题 / 需要什么前置 / 最终产出物是什么 |
| 3 | 环境搭建与数据准备 | 装什么（含版本）/ 测试数据从哪来 / 输入格式长什么样 |
| 4 | 核心代码流程 | 逐步拆：目标 → 完整代码 → 参数解释 → 预期输出 → 可视化 |
| 5 | 关键参数与调参指南 | 参数表 + 影响最大的那几个 + 不同数据规模怎么调 |
| 6 | 结果解读与质控 | 每张图怎么看 / 正常与异常分别长什么样 / 阈值定在哪 |
| 7 | 常见报错与解决方案 | 原文报错 + 按关键词分类的排查思路 + 版本兼容 |
| 8 | 可复用代码模板 | 函数化模板 + 最小可运行示例（MWE） |
| 9 | 延伸与进阶 | 局限性 / 替代工具 / 迁移检查清单 / 进阶推荐 |

⚠️ **模块 4 和模块 8 是两回事**，别合并。模块 4 是"教程怎么写的"（逐步、
带解释、给人读），模块 8 是"下次我怎么直接调"（函数化、参数在头上、给机器
跑）。合并的结果是两边都不好用：读起来啰嗦，复制起来还得改一堆硬编码。

## 二、拆解时要抓的四类东西

**1. 版本。** 教程里每一处 `library()` 的包，尽量标到版本号。生信流程的
大部分"跑不通"都发生在版本上（Seurat V4 → V5 的 `ScaleData`、
`FindVariableFeatures` 行为都变过），而教程正文通常不写版本。

**2. 阈值和它的理由。** 看到 `percent.mt < 10` 要追一句"为什么是 10"，
追不到就写「原文未披露」。**不要**替它编一个理由 —— 编出来的理由会被下
一个人当成事实引用。

**3. 踩坑点。** 教程里凡是出现「注意」「一定要」「否则会报错」的地方，
原样搬进模块 7，并补上**报错原文**。没有报错原文的坑，事后搜不到。

**4. 数据规模。** 同一套代码在 1w 细胞和 30w 细胞上要调的参数不一样
（内存、`npcs`、是否上 BPCells 之类的加速）。教程通常只给一个规模，
把"这套参数在什么规模下成立"显式写出来。

## 三、最小可运行示例（MWE）怎么写

模块 8 的 MWE 有一条硬标准：**别人复制走、不做任何修改就能跑出结果**。

所以它必须满足：
- 用**公开数据**（10x 官方的 pbmc3k 之类），不用教程配套的网盘链接；
- 从读数据到出第一张图**一条链走完**，中间不留 `# 此处省略`；
- 不依赖前一个代码块留下的变量；
- 跑得完（分钟级），不是"理论上能跑"。

⚠️ 给 MWE 之前**先在工作区里真的跑一遍**。生信教程里的示例代码常常有拼写
错误、过期的参数名、或者依赖某个已经被 deprecate 的函数 —— 没跑过就交出去，
用户拿到的是一份跑不通的笔记，而他会以为是自己环境的问题。

---

## 四、交付物与落盘

- 笔记文件落到工作区，文件名要能看出**是哪篇教程的**（`seurat-v5-scRNA-笔记.md`），
  不要叫 `笔记.md`。
- 要出 HTML 时：**图片必须 base64 写进 HTML 本身**（`base64enc::dataURI()`），
  不要用相对路径引外部目录 —— 用户经常要把单个 HTML 发给别人，带一个附件
  文件夹的话，对方打开就是一堆裂图。
- 笔记里保留**代码块的语言标注**（` ```r `），渲染出来才有高亮。

## 五、完整范例

本技能目录下的 `Biomamba代码分析skills-蒸馏笔记.html` 是一份**填满的**成品
（9 模块全填、Seurat V5 scRNA-seq 全流程），可以直接当模板看：
每一节该写到什么颗粒度、参数表长什么样、报错那一节怎么组织。

⚠️ 那是一份**单文件 HTML**（无外部依赖），用浏览器直接打开即可。要做成
同样形态的交付物时，照它的结构走。
