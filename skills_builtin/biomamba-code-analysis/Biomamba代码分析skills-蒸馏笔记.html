模块 4 · 核心代码流程

步骤 4.1 数据读取与对象创建

目标：把 10x 稀疏矩阵读入 R，创建带基础过滤的 Seurat 对象。
library(Seurat)
library(dplyr)

# 读取 10x 矩阵（data.dir 指向三件套所在目录）
counts <- Read10X(data.dir = "filtered_feature_bc_matrix/")

# 创建对象：min.cells=3 表示基因至少在 3 个细胞中表达才保留（去掉几乎不表达的影子基因）
#          min.features=200 表示细胞至少检测到 200 个基因（去掉空油滴/碎片）
seu <- CreateSeuratObject(counts, project = "sample1",
                          min.cells = 3, min.features = 200)
seu  # 预期输出：An object of class Seurat, 约 2w 基因 × 数千细胞
预期输出：Seurat 对象；seu@meta.data 含 nCount_RNA / nFeature_RNA 两列质控指标。

步骤 4.2 质控（QC）

目标：去掉低质量细胞（空油滴、死细胞、疑似双细胞）。
# 计算线粒体基因比例：人基因以 MT- 开头；小鼠要写 "^mt-"（Biomamba 强调的高频踩坑点）
seu[["percent.mt"]] <- PercentageFeatureSet(seu, pattern = "^MT-")

# 先看分布再定阈值——不要照抄别人的阈值
VlnPlot(seu, features = c("nFeature_RNA", "nCount_RNA", "percent.mt"), ncol = 3)

# 常规阈值：基因数 200-5000，线粒体 < 10%
seu <- subset(seu, subset = nFeature_RNA > 200 &
                         nFeature_RNA < 5000 &
                         percent.mt < 10)
【⚠️ 注意】① 线粒体阈值因组织而异：心肌、肝等高代谢组织天然 MT% 高，可放宽到 15–20%；② nFeature_RNA 上限实质是在去双细胞，样本差异大时建议分样本过滤；③ Biomamba 另有专贴《scRNA-Seq 双细胞过滤手册》（DoubletFinder/scDblFinder）。
预期输出：过滤后细胞数通常剩 60–90%；VlnPlot 三图用于截图留档（Figure S1）。

步骤 4.3 标准化、高变基因与缩放

# LogNormalize：每个细胞总 UMI 归一到 1e4 后取 log——消除测序深度差异
seu <- NormalizeData(seu, normalization.method = "LogNormalize", scale.factor = 10000)

# 选 2000 个高变基因（HVG）作为后续 PCA 输入，降低噪音
seu <- FindVariableFeatures(seu, selection.method = "vst", nfeatures = 2000)

# 中心化缩放；vars.to.regress 回归掉线粒体比例的影响（非必须，按需）
seu <- ScaleData(seu, features = VariableFeatures(seu), vars.to.regress = "percent.mt")
【⚠️ 注意】Seurat V5 提供 SCTransform() 一体化替代（NormalizeData+HVG+ScaleData），对测序深度差异大的样本效果更好；但 SCT 与常规流程差异分析逻辑不同，Biomamba 有专贴《SCTransform 与 ScaleData》辨析，二选一不要混用。

步骤 4.4 PCA 降维、聚类与 UMAP

seu <- RunPCA(seu, npcs = 50, verbose = FALSE)

# 用肘部图选 PC 数：曲线变平缓处即拐点（通常 15-25）
ElbowPlot(seu, ndims = 50)

dims_use <- 1:20                       # 依据 ElbowPlot 结果调整
seu <- FindNeighbors(seu, dims = dims_use)
seu <- FindClusters(seu, resolution = 0.5)   # 分辨率见模块 5 调参表
seu <- RunUMAP(seu, dims = dims_use)

DimPlot(seu, reduction = "umap", label = TRUE)   # 核心产出图
【⚠️ 注意】Biomamba 专门写过《单细胞分群分辨率选择困难症》与《为什么总把分辨率调的很高》：分辨率宁低勿高，先从 0.3–0.5 起步，结合 marker 生物学意义再细分；"分得细"不等于"分得对"。

步骤 4.5 多样本整合（Harmony 去批次）

# 多个样本分别创建对象后合并，或直接读取多样本合并矩阵
# seu_list 合并示例：
# seu <- merge(seu1, y = list(seu2, seu3), add.cell.ids = c("case1","case2","ctrl1"))

library(harmony)
seu <- NormalizeData(seu) %>% FindVariableFeatures() %>% ScaleData() %>% RunPCA(npcs = 50)

# Harmony 以样本来源列为批次变量，在 PCA 空间内校正
seu <- RunHarmony(seu, group.by.vars = "orig.ident")

# 后续降维聚类全部基于 harmony 空间而非 pca
seu <- FindNeighbors(seu, reduction = "harmony", dims = 1:20)
seu <- FindClusters(seu, resolution = 0.5)
seu <- RunUMAP(seu, reduction = "harmony", dims = 1:20)

# 检查整合效果：按样本着色，理想状态是同群细胞多样本混匀
DimPlot(seu, reduction = "umap", group.by = "orig.ident")
【⚠️ 注意】去批次并非越强越好——CCA 法整合强度高但可能抹平真实组间差异；样本间生物学差异大（如不同组织）时 Harmony 更温和稳妥。

步骤 4.6 Marker 鉴定与细胞类型注释

# 找每个 cluster 的 marker：only.pos 只保留上调基因，min.pct/logfc 控制宽松度
markers <- FindAllMarkers(seu, only.pos = TRUE,
                          min.pct = 0.25, logfc.threshold = 0.25)

# 每个群取 top10 画热图——检验 marker 特异性的最直观方式
top10 <- markers %>% group_by(cluster) %>% top_n(n = 10, wt = avg_log2FC)
DoHeatmap(seu, features = top10$gene) + NoLegend()

# 人工注释：依据已知 marker 字典逐群核对后重命名
new_ids <- c("0"="T cells", "1"="B cells", "2"="Mono", "3"="NK")  # 示例，按实际 marker 定
seu <- RenameIdents(seu, new_ids)
seu$celltype <- Idents(seu)
【⚠️ 注意】① 自动注释可用 SingleR + celldex 参考，但最终必须人工核对 marker（Biomamba 第 5 讲标题就是"细胞类型注释，从入门到入土"，足见其坑多）；② marker 计算慢时用 genesorteR（Biomamba 实测比 FindAllMarkers 快约百倍）；③ 大样本建议改用 pseudo-bulk 方案算 marker，更稳健。

步骤 4.7 组间差异分析

# 在指定细胞类型内做组间差异（case vs ctrl）
Idents(seu) <- "celltype"
fib <- subset(seu, idents = "Fibroblasts")
Idents(fib) <- fib$group          # group 列：case / ctrl

deg <- FindMarkers(fib, ident.1 = "case", ident.2 = "ctrl",
                   min.pct = 0.1, logfc.threshold = 0.25)
write.csv(deg, "fib_case_vs_ctrl_DEG.csv")

# 经典可视化：火山图
library(EnhancedVolcano)   # BiocManager::install("EnhancedVolcano")
# EnhancedVolcano(deg, lab = rownames(deg), x = "avg_log2FC", y = "p_val_adj")
【⚠️ 注意】应审稿人要求的标准做法：样本数 ≥3/组 时优先 pseudo-bulk（按样本聚合后用 DESeq2/edgeR），单细胞层面 FindMarkers 把细胞当重复会放大显著性（伪重复问题），Biomamba 有专贴《应审稿人要求 | pseudo bulk 差异分析》。

步骤 4.8 基因集富集分析（GO/KEGG）

library(clusterProfiler)
library(org.Hs.eg.db)

# SYMBOL 转 ENTREZID——富集分析的标准入口
deg_genes <- rownames(subset(deg, p_val_adj < 0.05 & abs(avg_log2FC) > 0.5))
ids <- bitr(deg_genes, fromType = "SYMBOL", toType = "ENTREZID", OrgDb = org.Hs.eg.db)

ego <- enrichGO(gene = ids$ENTREZID, OrgDb = org.Hs.eg.db,
                ont = "BP", pAdjustMethod = "BH", qvalueCutoff = 0.05)
dotplot(ego, showCategory = 15)      # 富集气泡图，论文常见图型

# KEGG 同理：ekegg <- enrichKEGG(gene = ids$ENTREZID, organism = "hsa")
【⚠️ 注意】bitr 转换会有部分基因丢失（不同数据库命名差异），属正常现象；想做通路水平比较而非基因列表富集，改用 GSEA 或 AUCell/UCell 打分（Biomamba《一文搞定单细胞基因集评分》）。

通用排查思路（按关键词分类）

  • 读取类：先 list.files() 确认文件名，再看解压层级，最后查文件完整性（gzip 损坏需重下）。
  • 版本类：报错出现在函数内部且提示对象不存在 → 90% 是包版本错配，sessionInfo() 对比教程环境，优先对齐 Seurat/SeuratObject/Matrix 三件套版本。
  • 内存类：对象规模超内存 1/3 就要换策略（分层对象、磁盘后端、抽样），不要硬扛。
【⚠️ 注意】Biomamba 反复强调："90% 的 bug 来自软件更新"——正式项目请锁定环境版本（renv 或镜像），教学用的开箱即用镜像就是为解决这个问题。

8.1 函数化模板（可直接复制进项目）

# ============================================================
# run_seurat_pipeline(): 单样本 Seurat 标准流程一键模板
# 输入:  counts_dir  = 10x 三件套目录
#        mt_pattern  = 线粒体基因前缀（人 "^MT-"，小鼠 "^mt-"）
#        dims_use    = PCA 使用维度（按 ElbowPlot 定）
#        res         = 聚类分辨率
# 输出:  完成质控+聚类的 Seurat 对象 + 三张质控图（对象属性 plot 中）
# ============================================================
run_seurat_pipeline <- function(counts_dir, mt_pattern = "^MT-",
                                min_feat = 200, max_feat = 5000, max_mt = 10,
                                dims_use = 1:20, res = 0.5) {
  library(Seurat)
  counts <- Read10X(counts_dir)
  seu <- CreateSeuratObject(counts, min.cells = 3, min.features = 200)
  seu[["percent.mt"]] <- PercentageFeatureSet(seu, pattern = mt_pattern)
  p_qc <- VlnPlot(seu, features = c("nFeature_RNA","nCount_RNA","percent.mt"), ncol = 3)
  seu <- subset(seu, subset = nFeature_RNA > min_feat &
                           nFeature_RNA < max_feat & percent.mt < max_mt)
  seu <- NormalizeData(seu) %>%
         FindVariableFeatures(nfeatures = 2000) %>%
         ScaleData(vars.to.regress = "percent.mt") %>%
         RunPCA(npcs = 50) %>%
         FindNeighbors(dims = dims_use) %>%
         FindClusters(resolution = res) %>%
         RunUMAP(dims = dims_use)
  seu@misc$qc_plot <- p_qc
  return(seu)
}

  • 需按项目改写：整合步骤（批次列名）、注释 marker 字典、差异分组列名。

模块 9 · 延伸与进阶

  • 本流程局限：① 未处理双细胞与环境 RNA（需 DoubletFinder / SoupX / CellBender）；② LogNormalize 对深度差异大的样本欠稳健；③ Harmony 属"温和去批次"，强批次场景需 CCA/scVI。
  • 替代工具对比：Scanpy（Python 生态，百万细胞更快）；SCTransform（一体化归一化）；scVI（深度学习整合，适合超大队列）；fastMNN（快速但内存友好）。
  • 迁移检查清单：物种（MT 前缀）→ 平台（10x/BD/华大，读取方式不同）→ 组织（MT 阈值）→ 样本量（整合方法+内存）→ 分组变量命名 → 参考注释库是否覆盖该组织。
  • 进阶推荐（Biomamba 进阶四件套）：monocle2/3 拟时序 → CellChat 细胞通讯 → SCENIC 转录因子 → copykat/infercnv 拷贝数变异；每块均有配套学习手册与专题班。
