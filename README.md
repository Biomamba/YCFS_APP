## 这是什么

**YCFS_APP 不是一个套了壳的 ChatGPT。** 它是把生信分析真正跑起来的那一层：
你描述分析目标，它调用封装好的技能（skills）、工具（MCP）和提示词，在**你自己的
工作区**里建目录、跑流程、出结果表，全程有进度、有日志、有产物。

它解决的是通用大模型直接分析生信数据时的那几个老毛病：

| 通用 AI 直接分析 | YCFS_APP |
|---|---|
| 给你一段看着对、跑起来报错的代码 | 代码在工作区里**真的被执行**，报错原文回给你 |
| 没有环境概念，装不上包就卡死 | 每个对话一块**隔离的工作区 + 独立 conda 环境** |
| 上传的文件散落各处，找不回来 | 完整的**文件管理系统** + 历史任务，产物可追溯 |
| 每次都要重新交代一遍要怎么做 | **技能 / MCP / 提示词** 封装好，挂上就用 |
| 上下文一长就开始失忆、烧 token | 参考示例不断丰富，**缓存命中率越用越高，越用越省** |

## 核心特点

### 1. 言出法随，不用写代码
说清楚要什么就行。技能、MCP、提示词都是现成的，挂上去就能用 —— 不需要你会 R、
Python 或者命令行。

### 2. 真执行，不是给提示词
分析在**你自己的工作区**里跑：真建目录、真跑流程、真出文件。历史任务、进度、
日志、结果表、产物下载，一条链路全都看得见。

### 3. 越用越省 token
不断丰富的参考示例 + 缓存命中优化。同一类分析做第二遍，比第一遍便宜得多。

### 4. 多端支持
- **网页版**：打开就能用，数据在服务器上
- **Windows 版 / macOS 版**：免安装，双击即用，**不依赖你本机装 R**
- **遥控服务器**：桌面版可以连到你的服务器上跑，重活不占本地
- 接入西柚云生态

### 5. 模型多端支持
国内外的模型都支持，都能转发 —— 想用哪个用哪个，也可以接自己的 key。

### 6. 团队协作
自己做科研是一个人，PI / 主任带队是很多人 —— 同一套东西都能无缝衔接，
成员、权限、任务归属都理得清。

### 7. 界面清晰、分区明确
左栏十几个功能分区，各有各的位置。**历史任务**、**文件管理**、**技能库**、
**环境管理** —— 通用 AI 缺的那几块，这里都是独立的一等公民。

### 8. 云工具（持续开发中）
带 GUI 的科研工具，不是让你自己写脚本。目前有**结合蛋白设计**流水线，单细胞分析、
TCGA 数据挖掘在开发中。**想用什么工具，来论坛说一声。**

### 9. 账号与历史跨机同步
换台电脑不用重新开始。账号信息、会话历史、技能、公告都能同步过来
（**分析工程文件不同步** —— 那是你自己机器上的数据）。

## 下载与安装

### 网页版（最省事）
直接访问：**<http://sw2-primary1.xiyoucloud.pro:34038/YCFS_APP/>**

注册即可用。目前 **App 本身免费**，token 和算力需要自备。

### Windows

1. 到 [Releases](https://github.com/Biomamba/YCFS_APP/releases) 下载
   `DS_App-Windows-*.zip`
2. **解压到一个纯英文路径**（比如 `D:\YCFS`），路径里有中文容易出问题
3. 双击里面的 `run_app.bat`
4. 首次启动会慢一点（要解压运行时），之后正常

> ⚠️ 杀软可能误报（没有代码签名，这是所有未签名 exe 的通病）。
> 加白名单即可，源码就在这个仓库里，可自行审计。

### macOS

1. 到 [Releases](https://github.com/Biomamba/YCFS_APP/releases) 下载对应架构的包：
   - Apple 芯片（M 系列）→ `DS_App-macOS-arm64-*.zip`
   - Intel 芯片 → `DS_App-macOS-x86_64-*.zip`
   - 不确定就点左上角  → 「关于本机」看「芯片」
2. 解压后双击 `run_app.command`
3. **首次打开会被 Gatekeeper 拦**（未签名/未公证）：右键点它 → 「打开」→
   再点一次「打开」。
   如果提示"已损坏"，在终端里跑一次：
   ```bash
   xattr -dr com.apple.quarantine /解压后的路径
   ```

> 桌面版打包进了一份**独立的 R 运行时**，你本机不需要装 R，也不会动你原有的环境。

## 服务器部署

在自己服务器上部署一份，供团队使用。要求：**Linux + R ≥ 4.1 + Shiny Server**。

```bash
# 1. 装依赖
sudo Rscript -e 'install.packages(c("shiny","bslib","httr2","callr","processx",
  "DBI","RSQLite","DT","commonmark","digest","jsonlite","curl","openssl"))'

# 2. 部署
bash deploy.sh
```

详细步骤（含 Nginx、HTTPS、systemd、备份、升级）见 **[DEPLOYMENT.md](DEPLOYMENT.md)**。

### 关键配置

| 环境变量 | 说明 |
|---|---|
| `DSAPP_DATA_ROOT` | 数据目录（库、文件、工作区都在这下面） |
| `DSAPP_ADMIN_EMAIL` | 指定平台管理员邮箱 |
| `DSAPP_SYNC_ALLOW_CREATE` | 允许通过同步包建号，**默认关**，中转服务器请保持关闭 |

> ⚠️ 平台第一个注册的账号会自动成为管理员。**只靠同步建号的服务器会永远没有
> 管理员** —— 请先在网页版注册一次，或预先设好 `DSAPP_ADMIN_EMAIL`。

## 账号同步与「跳板」

换台机器不用重来：账号、会话历史、技能、公告都能同步过来。同步走的是自研的
签名通道（**Ed25519** 签名，重放和篡改都会被拒），管理员可以在后台登记多个
**同步跳板**（中转服务器端点），客户端选一个用。

- **会同步**：账号、会话历史、技能、公告/论坛
- **不会同步**：分析工程文件（那是你机器上的数据）

## 技术栈

- **R + Shiny**（bslib / Bootstrap 5 主题，多套皮肤）
- **SQLite**（WAL 模式，单文件库）
- 自研的**分析执行器**：任务在独立进程里跑，节点可远程
- **Ed25519** 签名同步通道
- 桌面版：打包独立 R 运行时 + **字节码**分发（`compiler::cmpfun`），
  用户看不到明文源码

## 测试

这个仓库对"能不能用"这件事是**较真**的 —— 自检 4100+ 条，外加浏览器端探针。

```bash
# 源码/数据层自检
Rscript --no-environ selftest.R

# 浏览器验收（需要 Playwright）
bash tests/ui_v7/make_instance.sh 8977 /tmp/dsapp_test
python3 tests/ui_v166/probe_footer.py
```

自检里钉着很多"改错了不会报错、只会静默变坏"的东西（CSS 加载顺序、响应式失效、
非响应式字段定格……）。这些坑和它们的判据都写在 `tests/ui_v*/README.md` 里。
